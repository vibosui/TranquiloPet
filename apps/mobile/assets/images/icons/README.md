# Ícones de interface — Hospeda Patas

Arquivos definitivos previstos para a barra principal:

- `home.png`
- `hosting.png`
- `pets.png`
- `profile.png`

## Padrão recomendado

Os ícones são exibidos em aproximadamente 24 pt/dp na interface.

Para PNG raster, prefira exportar em fundo transparente e sem padding excessivo:

- `24x24 px` — 1x
- `48x48 px` — 2x
- `72x72 px` — 3x (arquivo recomendado como fonte de alta densidade)

Também é válido entregar SVG vetorial; a integração será feita quando os assets finais chegarem.

Os desenhos devem ser simples, legíveis em tamanho pequeno e, de preferência, monocromáticos para permitir aplicar as cores de estado ativo/inativo pelo app.

## Ícone do aplicativo

O launcher icon é outro asset e deve ser fornecido separadamente em PNG quadrado `1024x1024 px`.

Não confundir ícone de navegação/botão com ícone do aplicativo.
