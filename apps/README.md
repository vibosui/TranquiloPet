# Aplicativos

## `mobile`

Aplicativo principal do Tranquilo Pet, criado com Expo SDK 54, React Native e Expo Router.

Antes de iniciar, configure `apps/mobile/.env.local` com o IPv4 do computador que executa o monitor local. O monitor é opcional para abrir a interface, mas necessário para persistir o cadastro deste laboratório.

Para iniciar pela raiz do repositório:

```powershell
npm.cmd run start
```
